Aromiqo India — responsive spice store website

1. Open index.html in a browser.
2. The assets folder contains product/category images cropped from the supplied reference image.
3. Replace the placeholder phone/email/WhatsApp number before publishing.
4. Product names, prices and descriptions can be edited in the products array near the bottom of index.html.
5. This is a frontend demo: payment gateway, database, login and real order processing are not connected yet.
